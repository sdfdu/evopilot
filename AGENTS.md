# EvoPilot contributor guidance

- Preserve the local-first, dependency-free core unless a change has measured benefit.
- Treat explicit user instructions as higher priority than learned memory.
- Never store secrets, raw tool inputs, or raw tool outputs as behavioral observations.
- Require human approval for destructive, external, financial, credential, system-wide, publication, and MCP-permission changes.
- Add tests for observable behavior and failure boundaries.
- Validate all changed Skills and the plugin manifest before completion.
