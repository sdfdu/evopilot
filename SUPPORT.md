# Support

## Before opening an issue

Run:

```bash
python plugins/evopilot/scripts/evopilot.py doctor --plugin-root plugins/evopilot
python -m unittest discover -s tests -v
```

Check [How to use EvoPilot](docs/how-to-use.md) and search existing issues.

## Where to ask

- Use a bug report for reproducible incorrect behavior.
- Use a feature request for a concrete capability or workflow.
- Use GitHub Discussions for setup questions, design proposals, and general feedback.
- Follow [Security](SECURITY.md) for vulnerabilities; do not disclose them in public issues.

Include the EvoPilot version, Python version, operating system, reproduction steps, expected behavior, and sanitized diagnostic output. Never attach an EvoPilot database, secrets, raw prompts, private paths, or personal memory.
