# Application Tailor

1. Read the target posting and the experience the user provides or identifies. Use the posting to extract core responsibilities, required qualifications, and preferred skills.
2. Match requirements to specific evidence such as a project, coursework, or work experience. Mark gaps explicitly. Use metrics and outcomes only when the user or a source supports them.
3. Draft the requested deliverable in the posting's or user's preferred language. Write resume bullets around actions and outcomes, and use situation, task, action, and result for interview stories when those details are available.
4. Flag claims the user needs to confirm and suggest concrete evidence they could add. Keep drafts local or in the requested document and ask before submitting or contacting anyone unless the user has already authorized that exact action.
