# Decision Capture

1. Identify the option the user confirmed, its rationale, and its scope. Keep proposals and unresolved points distinct from the decision. Mark missing rationale or revisit conditions as unspecified.
2. Use the project's existing decision log or architecture decision record conventions. Search for the same decision first and update it when appropriate. If there is no convention, use a descriptive Markdown file in the project's documentation.
3. Record the decision, date, rationale, scope, and conditions for revisiting it. Include alternatives and consequences only when they were discussed or are supported by the project.
4. Link the relevant issue, file, or evidence when available. Summarize the decision without copying private conversations or tool logs. Confirm the saved location and any open points.
