# 簡報視覺設計

## 確認改動範圍

- 新製簡報：依受眾、使用情境（現場投影或自行閱讀）及指定格式建立視覺系統。改版既有簡報：先看縮圖與代表頁，區分必須保留的母片、品牌元素與可重做的版面；若只要求美編，不自行改寫結論、數字、頁序或刪頁。
- 把參考檔當成內容來源、風格參考或必須沿用的母片，依使用者指示判斷。未指定風格時，直接依情境選擇，不必先詢問配色；指定品牌或風格時，以指定規範為準。
- 用目前環境支援的簡報工具製作，遵守指定格式。純視覺審查不改原檔，回報頁碼、具體問題與建議改法，先列影響理解的問題。

## 先決定每頁要讓人看見什麼

為每頁寫下「觀眾先看到什麼、接著看哪項證據」。依資訊關係選版型，不要把不同內容一律塞進卡片：

| 頁面目的 | 建議版型 |
| --- | --- |
| 傳達一項發現 | 結論標題＋單一主圖或關鍵數字；就近補上基準、期間或樣本 |
| 比較方案或組別 | 並排共用比較基準；比較數值用對齊長條，需要精確查值才用表格 |
| 說明趨勢 | 折線圖＋就地標註關鍵轉折；保留單位和時間尺度 |
| 說明流程或方法 | 有順序才用箭頭；階段、輸入與輸出放在對應位置 |
| 呈現研究證據 | 主圖優先，方法提示與限制放在讀圖所需的位置；勿移除誤差、樣本數或必要來源 |

## 建立可重複使用的版面規則

- 先做一張典型內容頁和一張最密集的資料頁，測試共同邊界、字級層次、間距和圖表標籤，再套用全篇。密集頁裝不下時先重排；獲准調整內容或頁數才精簡、拆頁或移至附錄。
- 定義背景、正文、輔助資訊、強調色四種角色；同色跨頁維持同義。要比較的頁面共用網格與圖表尺度；若尺度不同，須讓差異清楚可見。別只靠顏色區分系列或狀態。
- 優先保留原生文字、圖形與可編輯圖表。圖片不能拉伸；文字不要烙在背景圖上。圖表美化不改數據、統計定義或結論；沒有原始數據時，不憑像素反推數值。
- 繁體中文選擇字形完整的字體，檢查混排、標點換行與字體替代。投影頁優先放大主文與圖例；閱讀版可容納較多細節，但不能靠過小字體解決溢出。

## 驗收與交付

1. 看全篇縮圖：檢查視覺節奏、共用邊界、標題層次及顏色是否一致。
2. 逐頁看實際渲染：檢查裁切、重疊、意外換行、低對比、圖例與標籤可讀性。若工具沒有渲染能力，說明未做視覺驗收，不把結構檢查當作預覽。
3. 比對原稿或來源：檢查數字、單位、來源與重要限制是否保留。若執行了美編，交付使用者指定的檔案或預覽，簡述實際變更和未檢查項目。
