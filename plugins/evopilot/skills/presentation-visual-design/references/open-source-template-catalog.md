# 開源模板索引

來源：[hornhuang/ppt_themes](https://github.com/hornhuang/ppt_themes)。這是一個以學校答辯與工作簡報為主的公開模板整理庫，包含大量 PPTX 範例與預覽素材。它適合做候選版型研究，不代表每個收錄檔案的原始素材都能無條件重新發布。

## 依用途選擇

| 需求 | 優先搜尋的類型或檔名線索 | 可抽取的設計語法 |
| --- | --- | --- |
| 論文、畢業或學術答辯 | `学术答辩`、`论文答辩`、`毕业答辩`、`严谨风` | 章節節奏、研究流程、方法與成果頁、穩定的標題基線 |
| 醫療、生命科學或教育 | `医科`、`清新`、`教育课件` | 高留白、淺色背景、低飽和強調色、圖文並排 |
| AI、軟體或產品提案 | `互联网科技风`、`商业计划科技类`、`科技型产品介绍` | 深色封面、技術流程、功能模組、成果數字與產品截圖 |
| 商業、專案或工作報告 | `企业简介`、`项目汇报`、`商务风`、`商业企划书` | 結論標題、KPI 卡片、時間軸、比較表與決策頁 |
| 文化、品牌或故事型內容 | `中国风传统文化`、`文化宣传`、`手绘风` | 主視覺、章節轉場、插畫語彙、較強的圖片敘事 |
| 深色、穩重或高端提案 | `深蓝沉稳`、`高端实用商务`、`靛蓝色简约` | 深色底、單一重點色、少量大圖、低噪音資訊層級 |

## 研究模板時先看什麼

1. 先看封面、章節頁、最密集的資料頁與結論頁，不要只挑封面。
2. 記錄畫布比例、共同邊界、標題位置、正文最小字級、圖表標籤位置與頁碼規則。
3. 分辨哪些元素是可泛化的版型，哪些只是該模板的品牌或主題素材。
4. 從 2–3 個候選模板合併成一套 design system；只保留一套字體階層、網格與色彩角色。

## 安全使用

- Repo 的 README 宣稱採 MIT，但也說明收錄模板並非全部原創；因此使用前仍需確認所選檔案、內嵌圖片、字體、圖示與品牌素材的個別授權。
- 不把整批模板複製到生成結果或 skill assets。只有在使用者明確需要可編輯母片且授權清楚時，才引用特定 PPTX；一般情況只抽取設計規則並重新製作可編輯元素。
- 交付時在備註或來源頁列出使用的 repo、模板檔名與需要保留的授權資訊。
